# 슥따디(sseukstudy) — Claude Design용 UI/UX 디자인 프롬프트

> 이 문서를 Claude Design에 그대로 붙여넣어 사용한다.
> 범위: 1단계(MVP) 전체 화면 + 2단계(메일 알림) 설정 화면. AI 튜터(3단계)는 제외하되 확장 여지만 남긴다.

---

## 0. 요청 요약

"슥따디"라는 **스터디 그룹 목표·일정 관리 웹 서비스**의 UI/UX를 디자인해 줘.
핵심 가치는 **"누가 어떤 목표를 어디까지 해냈는지 한눈에 보인다"** 이다.
데스크톱 웹을 우선으로 하되, 모바일(360px~)에서도 주요 흐름(목록 보기·과제 제출·알림 확인)이 가능해야 한다.
UI 언어는 한국어.

### 산출물
1. 디자인 토큰 (컬러·타이포·간격·라운드·그림자, 라이트/다크)
2. 공통 컴포넌트 (헤더, 카드, 상태 아이콘, 아바타 스택, 배지, 트리 노드, 빈 상태 등)
3. 아래 §4의 화면 전체 (데스크톱 1440, 주요 화면은 모바일 390도)
4. 핵심 인터랙션 흐름 프로토타입: 방 만들기 → 커리큘럼 편집 → 참가 → 과제 제출 → 진척 확인

## 2. 도메인 규칙 (화면에 반영돼야 하는 것)

### 2.1 스터디 방 (= 1단계 목표)
- 필드: 제목, 한 줄 소개, 상세 설명(마크다운), 운영규칙(마크다운), 시작일/종료일, 최대 인원(필수), 최소 인원(선택), 공개/비공개, 참가 방식(바로 참가 / 그룹장 승인), 그룹장도 과제 수행(기본 ON), 커버 이미지(선택), 태그
- 상태: **모집중 → 진행중 → 종료** (+ 보관)
  - 시작일 00:00(KST) 자동 진행중 전환, 그룹장 "지금 시작"으로 조기 시작 가능
  - 종료일 다음날 자동 종료
- 참가·참가 취소는 **모집중에만** 가능
- 최대 인원 도달 시 참가 버튼 **비활성화** ("정원 마감")
- 승인제: 신청 → 승인 대기 → 승인/거절. 대기자는 정원에 미포함, 신청 취소 가능, 시작일에 미처리 대기는 자동 만료
- 공개 방: 카드 그리드 노출 + **비로그인 열람 가능**(읽기 전용, 참가 클릭 시 로그인 유도). 말단 과제 1개 이상 있어야 모집 시작 가능
- 비공개 방: 초대 링크로만 진입

### 2.2 목표 트리 (커리큘럼)
- 깊이: 방(1단계) 아래 2~5단계. **2단계 노드 = "회차"** (예: 1주차, 2주차)
- 모든 노드에 기간(시작일~마감일)과 설명을 넣을 수 있음
- **과제는 말단(leaf) 노드에만** 존재
- 과제 유형: **공통**(활성 참가자 전원) / **지정**(특정 인원 선택). 지정은 모집 중 "담당자 미정" 허용, 시작 전 경고
- 그룹장만 편집. 진행 중에도 수정 가능하지만 제출물이 있는 과제는 삭제 대신 "보관"
- 상위 노드 진척률 = 하위 과제의 (제출 수 ÷ 담당 건수) 자동 집계

### 2.3 과제 제출
- 개인 제출만 (공동 제출 없음)
- 내용: 마크다운 본문 + 링크 여러 개 + 파일 첨부(1개 10MB, 최대 5개, 이미지/PDF/zip/텍스트)
- 제출 후 무제한 수정. 같은 방 참가자 모두 열람 가능 (비로그인·외부 비공개)
- 기한 후 제출 허용 → "지각"으로 표시 (최초 제출 시점 기준 고정)

### 2.4 사람별 상태 (가장 중요한 시각 언어)

| 상태 | 의미 | 기본 표현(제안) |
|---|---|---|
| 예정 | 과제 시작 전 | 회색 점선 원 |
| 진행중 | 기간 내, 미제출 | 빈 원 ⚪ |
| 기한내 제출 | 마감 전 제출 | 초록 채운 원 + 체크 🟢 |
| 지각 제출 | 마감 후 제출 | 노랑 채운 원 + 시계 🟡 |
| 미제출(경과) | 마감 지남, 미제출 | 빨강 원 + ! 🔴 |
| 이탈 | 그룹장이 비활성 처리한 참가자 | 회색 아바타 + "이탈" |

- **색만으로 구분하지 말 것** (색약 대응: 모양/아이콘 병행)
- 아바타 + 상태 아이콘 조합이 캘린더·칸반·간트·참가자 목록 전반에 반복 사용됨 → 하나의 컴포넌트로 설계
- 인원이 많으면 `🟢🟢🟡 +3` 형태로 접고 클릭/호버로 펼침
- 과제 단위 요약 표기: `2/3 제출` + 미니 프로그레스

### 2.5 알림
- 헤더 프로필 옆 🔔 + **안 읽은 개수 배지**
- 드롭다운: 알림 목록(아이콘·문구·방 이름·상대 시간), 클릭 시 대상 이동+읽음, "모두 읽음"
- 알림 종류: 회차 시작, 과제 전원 제출(그룹장), 참가 신청/승인/거절, 마감 임박 리마인더, 지정 과제 배정/재지정, 일정 변경, 스터디 시작/종료

### 2.6 태그
- 커리큘럼 저장 시 AI(Jev)가 태그 사전에서 자동 선택 → 칩 형태 표시, "자동" 표식
- 그룹장이 삭제/추가 가능 (사전 자동완성 + 자유 입력)

## 4. 화면별 요구사항

### 4.1 로그인 / 온보딩
- 이메일 1필드 → "인증 코드 받기" → 6자리 OTP 입력(자동 포커스 이동, 재전송 타이머)
- 이름 입력 없음. 최초 로그인 시 **닉네임 설정**(2~16자, 실시간 중복 체크)
- 초대 링크로 들어온 경우 로그인 후 원래 방으로 복귀

### 4.2 방 목록 (메인, 카드 그리드)
- 반응형 그리드 (데스크톱 3~4열, 태블릿 2열, 모바일 1열)
- 필터 탭: `전체 공개 방` / `내가 참가한 방` / `내가 만든 방` + 상태 필터(모집중/진행중/종료) + 태그 필터 + 검색
- **카드 구성**: 커버(없으면 태그 기반 자동 그라디언트/패턴) · 상태 배지 · 제목 · 한 줄 소개 · 기간 · 인원 `3/6` · 태그 칩 · 참가 방식 아이콘(승인제 🔒) · 비공개 표시
  - 내가 참가한 진행중 방 카드: **내 진척률 바** + 다음 마감 과제 1개 표시
- "방 만들기" 주요 CTA (채팅방 만들듯 가볍게)
- 빈 상태: 참가한 방이 없을 때 / 검색 결과 없음

### 4.3 방 만들기
- **한 화면, 가벼운 폼** (채팅방 개설 느낌). 필수 항목만 펼침, 선택 항목은 "더 설정하기"로 접힘
  - 필수: 제목(= 최상위 목표), 한 줄 소개, 기간, 최대 인원, 공개/비공개 토글, 참가 방식(바로/승인)
  - 선택: 상세 설명, 운영규칙(마크다운 에디터), 최소 인원, 그룹장도 과제 수행, 커버 이미지
- 생성 후 → 방 상세의 **커리큘럼 탭(편집 모드)** 으로 이동, "첫 회차를 추가해 보세요" 가이드

### 4.4 방 상세 — 공통 레이아웃
- **좌측(메인)**: 탭 콘텐츠
- **우측 사이드 패널** (고정):
  - 방 상태 배지, 기간, D-day
  - **참가 버튼** 상태별 변형: `참가하기` / `참가 신청`(승인제) / `승인 대기중 · 신청 취소` / `참가 취소`(모집중 참가자) / `정원 마감`(비활성) / `모집 종료`(비활성) / 비로그인 `로그인하고 참가`
  - 인원 `4/6` + 최소 인원 충족 여부
  - **참가자 목록**: 아바타·닉네임·역할(그룹장 👑)·전체 진척률 미니바, 이탈자 회색
  - 그룹장 전용: 승인 대기 목록(승인/거절 버튼, 정원 차면 승인 비활성), 초대 링크 복사
- 모바일: 사이드 패널은 하단 고정 참가 버튼 + 시트로 전환

### 4.5 개요 탭
- 최상위 목표(제목) 크게, 소개, 상세 설명, **운영규칙**, 전체 일정 요약(회차 목록 + 기간), 태그(자동/수동 구분)
- 진행중이면 상단에 "현재 회차" 하이라이트 카드 + 전체 진척률

### 4.6 커리큘럼 탭 (목표 트리)
- **보기 모드**: 접기/펼치기 트리. 노드마다 제목·기간·(말단) 과제 유형 배지 `공통`/`지정`·담당자 아바타·상태 요약 `2/3`
- **편집 모드(그룹장)**:
  - 노드 추가(하위/형제), 들여쓰기·내어쓰기, 드래그 정렬, 인라인 제목 편집
  - 깊이 5 도달 시 "하위 추가" 비활성 + 툴팁
  - 노드 상세 편집 패널(사이드 드로어): 제목, 설명(마크다운), 기간, 말단이면 과제 유형 + 담당자 선택(참가자 멀티 셀렉트, "담당자 미정" 경고 표시)
  - 제출물 있는 노드 삭제 시 → "보관" 확인 다이얼로그
  - 저장 후 태그 자동 갱신 토스트
- 시작 전 검증 배너: "담당자가 지정되지 않은 과제 2개"

### 4.7 보드 탭 (칸반)
- 토글: **내 칸반 / 팀 칸반**
- 컬럼: `예정` → `진행중` → `제출완료` (자동 배치, 드래그 없음)
- 카드: 과제 제목 · 상위 회차 경로(breadcrumb) · 마감일/D-day · 유형 배지
  - 내 칸반: 내 상태 아이콘, 기한 경과 미제출은 진행중 컬럼에 🔴 강조
  - 팀 칸반: 담당자 아바타+상태 스택, `2/3 제출`, 전원 제출 시 ✅ 완료 배지
- 회차 필터

### 4.8 캘린더 탭
- 월간 / 주간 전환, 오늘 이동
- 말단 과제 = 기간 막대, **마감일 셀에 담당자별 상태 아이콘** (`+N` 접기)
- 회차(2단계) 시작일 마커
- 필터: `전체` / `내 과제만` / **특정 참가자 선택** (그 사람의 달성 흐름을 한눈에)
- 막대 클릭 → 과제 상세 팝오버(담당자 상태 목록 + "과제로 이동")

### 4.9 간트 탭
- 좌측: 목표 트리(5단계 접기/펼치기), 상위 노드는 **진척률 바 + %**, 말단은 담당자 상태 아이콘
- 우측: 타임라인(일/주 단위 줌), 기간 막대, **오늘 세로선**
- 읽기 전용 (드래그 수정 없음). 막대 색/패턴으로 상태 표현(완료/진행/지연)

### 4.10 과제 상세 + 제출
- 상단: 경로(방 › 회차 › … › 과제), 제목, 기간·D-day, 유형/담당자, 설명
- **내 제출 영역** (담당자일 때):
  - 마크다운 에디터(미리보기 탭) + 링크 추가 리스트 + 파일 드롭존(용량/개수 제한 안내, 업로드 진행률)
  - 상태: 미제출 / 제출됨(제출 시각, 지각 여부) / 수정 중
  - 제출 후 "수정" 가능, 마지막 수정 시각 표시
- **참가자 제출 현황**: 담당자 리스트(아바타·상태 아이콘·제출 시각) → 클릭 시 해당 제출물 펼쳐보기
- 담당자 아닌 사람: 제출 영역 대신 "담당 과제가 아닙니다" + 열람만
- 전원 제출 시 상단 ✅ "모든 담당자가 제출했어요" 배너
- (3단계 확장 여지) 제출물 하단에 "AI 튜터 피드백" 영역이 붙을 수 있게 공간 고려만

### 4.11 설정 탭 (그룹장)
- 방 정보 수정 (모집중 이후 일부 필드 잠금 표시)
- **참가자 관리**: 목록, 진행중 참가자 **비활성(이탈) 처리** → 다이얼로그에서 해당 인원의 미제출 지정 과제별로 `제외` / `재지정(참가자 선택)` 선택. 담당자 0명이 되는 과제는 재지정 강제
- **알림 설정** (2단계, 디자인은 지금):
  - 기본 알림(끄기 불가, 잠금 표시): 회차 시작 / 과제 완료 요약 / 참가 승인
  - 옵션 알림 토글: 마감 리마인더(1일 전/3일 전) / 지정 과제 배정 / 일정 변경 / 시작·종료
  - 완료 알림 방식: `일일 요약(기본)` / `즉시`
- 위험 영역: 모집중 → 방 삭제 / 진행중 이후 → 보관

### 4.12 초대 링크 진입
- 방 미리보기(제목·소개·기간·인원·그룹장) + 참가 버튼. 비로그인이면 로그인 → 복귀

### 4.13 내 프로필
- 닉네임 변경, 아바타, 이메일(읽기 전용)
- "옵션 알림 메일 전체 끄기" 토글 (기본 알림은 항상 발송 안내)

### 4.14 헤더 (전역)
- 로고 · 방 목록 · 검색 · 🔔(배지) · 프로필 메뉴(내 프로필/로그아웃)
- 비로그인: 로고 · 로그인 버튼
